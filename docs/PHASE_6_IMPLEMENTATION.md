# Phase 6 — AI Research Loop

## Implemented

`trading_lab.ai_research` introduces the AI orchestration layer where an autonomous strategy-generation agent can interact with the lab using strict security borders.

Key features implemented:
- **Provider Protocol**: Defined `AIProvider` to abstract actual LLM inference endpoints away from the domain.
- **Mock LLM (`MockAIProvider`)**: Added a simulated LLM generator to allow tests and pipeline runs without live API costs.
- **Immutable Research Loop (`ResearchLoop`)**: The orchestration loop forces AI proposals to be logged durably before execution. The AI never bypasses the backtester or risk engines.
- **Auditing**: Emits `AI_RESEARCH_NOTE` audit events to securely trace strategy performance analysis generated by the AI model.

## Limitations
- AI output is fully mocked in Phase 6. Live integration with OpenAI/Anthropic/Gemini APIs requires API keys (recorded in `requirement_by_boss.md`).
- The AI cannot modify past experiment results or erase failed backtest histories.

## Verification

`tests/test_phase6_ai.py` ensures that a strategy generated by the Mock AI is correctly transformed into a versioned specification, deterministically run, and permanently persisted to the database.

Run tests:
```sh
.venv/bin/python -m pytest
```
